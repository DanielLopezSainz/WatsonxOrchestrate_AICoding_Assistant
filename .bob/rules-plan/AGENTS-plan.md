# Plan mode

Owner: Daniel Lopez Sainz, IBM. Last reviewed: 2026-09-18.

Write the design to `design/<name>-design.md` and nothing else. Import nothing, create nothing on the instance, run no commands.

The design must let the user judge, without reading code: what was asked, what on the instance is reused, what will be built and in which order, how the agent behaves, and how it will be tested (the questions, and what a correct answer contains).

Show the file and end with "Waiting for your approval before building." Revise it when asked. Build nothing until the user approves.
